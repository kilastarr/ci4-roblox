⚙️ White Box View (Roblox Controller Logic)

Transparansi Kode: Jalur logika (Independent Path) yang dieksekusi oleh Controller:

public function store() {
$nama = $this->request->getPost('nama_game');
$pemain = $this->request->getPost('pemain_aktif');
if (empty($nama)) {
return "Error: Nama game tidak boleh kosong!";
} else if ($pemain < 0) {
return "Error: Jumlah pemain aktif tidak valid!";
} else if ($pemain > 1000000) {
return "Error: Angka pemain aktif melebihi batas rasional!";
} else {
$this->robloxModel->save([...]);
return "Sukses: Data game Roblox berhasil disimpan!";
}
}
